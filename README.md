# VV Frontier · AI R&D Laboratory

Личная лаборатория прикладных исследований ИИ. Превращает материал из Telegram
или ссылку в план с памятью, разбор с критиком, сравнение условий и сохранённое
знание. Публикация готового поста требует отдельного подтверждения.

**v0.20.1-alpha.1 · Windows x64 · один владелец · локальное развёртывание**

> Local-first applied AI research workbench with approval, personal memory,
> source evidence, comparisons and publication drafts. This alpha is a personal
> Windows application with a Russian-language interface.

```text
Материал → задача и baseline → память и план → ваш апрув
         → исследование → отчёт, графики и пост → база знаний
                            → отдельное «В очередь» → ваш канал
```

## Запустить

1. Установите **64-битный CPython 3.11, 3.12 или 3.13** с [python.org](https://www.python.org/downloads/windows/).
2. Скачайте архив приложения из [GitHub Releases](https://github.com/VasilyKolbenev/AI-R-D-laboratory/releases)
   и распакуйте в короткий путь, например `C:\AI-Lab`.
3. Откройте **Setup-Laboratory.cmd**. Он создаст `.venv` и установит зависимости
   из PyPI; нужны интернет и место для окружения и медиа.
4. Откройте **Open-Laboratory.cmd** → [http://127.0.0.1:8795](http://127.0.0.1:8795).
   **Stop-Laboratory.cmd** останавливает эту установку.

Установка и открытие интерфейса не запускают исследование. Git, Node.js,
администратор и локальная модель для запуска приложения не нужны.
Для исследования подключите установленный нативный Codex CLI или Claude Code CLI
со своим входом в аккаунт; их лимиты и условия действуют отдельно.

## Что работает

| Шаг | Возможности |
| --- | --- |
| Входящие | Текст, URL, выбранные пересылки личному Telegram-боту, импорт Telegram JSON |
| План | Задача, baseline, метрики, условия, источники, выбранные память и уроки, исполнитель и бюджет |
| Исследование | Один проход или три: исследователь с прикладным сравнением → критик → редактор; журнал и частичные результаты |
| Знания | Профиль интересов, поправки, версионируемые выводы и уроки с доказательствами и границами применимости |
| Проверка | Связи утверждений с источниками, сопоставимые числовые сравнения, явные пробелы и ограничения |
| Результат | Полный отчёт, краткий пост, PNG/SVG, MP4; два оформления и графики при наличии сопоставимых данных |
| Публикация | Предпросмотр → отдельное «В очередь» → назначенный слот; свои канал, дни и время |
| Эксплуатация | SQLite, локальные резервные копии, проверка восстановления, наблюдатель и экспорт |

В новой базе выбран **один проход**, 180 секунд, 3 вызова CLI за 24 часа;
веб-поиск выключен. Три прохода с критиком и проверку источников выбирают явно
до подготовки плана. Три прохода резервируют три суточных слота; квота сама
не повышается.

Главный интерфейс — «Реактор»; «Обсерватория» помогает проверять доказательства.
`/workbench/` содержит исследовательский стол, таблицу знаний, сравнения и
CPU-эксперименты; рабочие формы и настройки доступны из основной лаборатории.

## Что считается доказательством

Завершившиеся агенты не означают, что технология испытана на вашей задаче.
Лаборатория различает анализ источников, внешние результаты, собственные измерения
и иллюстративную схему. Привязка цитаты подтверждает происхождение,
а не научную истинность. Неизвестные показатели не заменяются нулями.

Встроен **один фиксированный CPU-кейс**: TF-IDF против BM25 на BEIR/SciFact,
5 183 документа и 300 test-запросов. Отдельные план и апрув; nDCG@10, Recall@100,
MRR@10, время, выдачи и протокол. Данные загружаются отдельно, модели и API
не используются. Это проверка лексического поиска, а не всех RAG-систем,
памяти агентов или произвольной технологии.
[Методика и лицензии данных](docs/research/lexical-pilot.md).

## Данные, расходы и ограничения

- Материалы и история хранятся в `.lab-data`; релиз не содержит рабочей базы,
  токенов, очереди или готовых исследований автора.
- Апрув плана разрешает передачу выбранного контекста исполнителю.
  Веб-поиск, Telegram и CLI требуют сети. Подписки в релиз не включены.
- Лимит вызовов и время видны до апрува. Таймаут может оставить
  `outcome_unknown`: расход неизвестен; автоматического платного повтора нет.
- Токены поддерживаемых подключений шифруются Windows DPAPI и привязаны к
  профилю. Копия на том же диске не защищает от потери диска.
- Для Telegram и расписания компьютер должен работать, иметь сеть и не спать.
  Автозапуск настраивается отдельно; Setup не меняет режим сна.
- Сервер слушает `127.0.0.1`. Аккаунты пользователей, изоляция арендаторов
  и публичный SaaS в эту поставку не входят.
- Поддерживаемый путь установки этой альфы — Windows x64.
  Linux/macOS и произвольные бенчмарки не заявлены как проверенные сценарии.
