# Changelog

## v0.21.0-alpha.4 · 2026-11-13

- Connects pinned local AntV Infographic 0.2.20 and G2 5.4.8 bundles to VisualSpec.
  Software loads from the local server with browser integrity checks and retained
  upstream licenses; no CDN, icon/font service or model call is needed.
- Compatible saved process paths use a responsive AntV sequence with exact node
  evidence selection. Branches, feedback and meaningful edge labels retain the
  native graph rather than losing their semantics in a template.
- Corpus trends use interactive G2 plots with exact paper-share tooltip/readout
  and the existing year/cohort/source drilldown. Native rendering remains a
  disclosed fallback if a library or render fails. Production CSP stays strict.

## v0.21.0-alpha.3 · 2026-11-13

- VisualSpec binds an automatic, deterministic visual plan to the exact saved
  report or corpus snapshot. No routing model, research or external call is used.
- Evidence-eligible comparisons take priority; saved conceptual mechanisms and
  reproducible corpus prevalence trends have separate explicit provenance.
- Brief and corpus views consume the shared contract and explain their selection.
  Missing comparisons, relation graphs, simulations and videos are not fabricated.
- Preferred visualization engines and the currently available native renderers
  are distinct. Third-party skill kits/libraries are not installed by this update.

## v0.21.0-alpha.2 · 2026-11-13

- A concise visual brief opens by default: problem, saved mechanism, applicability,
  constraints and comparison evidence, with complete text available on demand.
- Numeric comparison charts require the existing source-bound `chart_eligible`
  projection. Missing results stay unknown; contextual memory links are not baselines.
- Secondary tools move into a disclosure. Reactor, Observatory, the detailed report,
  corpus and existing approval/publication workflows remain accessible.

## v0.21.0-alpha.1 · 2026-11-13

- Optional pinned Drift Inspector corpus: papers, external contribution claims,
  canonical topic assignments and a separately identified balanced analysis sample.
- Recomputed distinct-paper topic/year shares are checked against all 486 published
  values. Charts expose their numerator and denominator papers and source abstracts.
- The existing workbench gains a read-only corpus mode with source/claim drill-down;
  no extraction, embedding, clustering, research approval or Telegram send occurs.
- Immutable corpus sidecars are included and validated in full operational backups.
  JSON research export remains separate. Setup/runtime gain no model dependencies.

## Unreleased · 2026-10-27

- Telegram plan approvals and `/status` show the current rolling 24-hour CLI
  reservation budget and the earliest eligible Moscow time for that plan.
- An exhausted budget no longer suggests refreshing the plan to unlock it.
  Limits, reservations, existing approvals and the no-automatic-retry policy stay unchanged.

## v0.20.1-alpha.1 · 2026-10-26

- GitHub repository captures prioritize the README instead of page navigation.
  A new plan may re-extract cached original bytes without HTTP; existing captures,
  plans, reports and their provenance remain unchanged.
- Long channel drafts try a compact surface with shorter static labels and notices.
  Required model paragraphs, numeric conditions, sources and the 3500 UTF-16 limit
  remain intact. A genuinely oversized mandatory body still blocks publication.
- The first maintainer pilot exposed both defects. Corrected extraction does not
  retroactively turn its saved qualitative report into a measured comparison.

## v0.20.0-alpha.1 · 2026-10-26

First packaged Windows x64 local alpha of the working personal laboratory.

- Dedicated setup and virtual environment; launch/stop without the developer's cache.
- Reactor, evidence Observatory and structured research workbench.
- Telegram intake, explicit approval, Codex/Claude selection, memory and lessons.
- Opt-in three-pass research with critic/editor, usage journal and checkpoint continuation.
- Reports, provenance, knowledge, PNG/SVG/MP4 and owner-approved publication queue.
- Fixed CPU TF-IDF/BM25 evaluation with optional BEIR/SciFact data and separate approval.
- Local backup, restore checks, exports and crash supervision.
- Current onboarding, pilot, security boundary, license and component notices.

The archive contains source and setup instructions, not the author's working data,
credentials, queue, subscriptions or recorded studies. No multi-user hosting or
universal benchmark executor is introduced.

Versions 0.1–0.19 were local development increments. Relevant design decisions are
in `docs/adr/`; historical prototypes and architectural plans are in
`deliverables/`. Those plans do not claim all future acceptance gates passed.
