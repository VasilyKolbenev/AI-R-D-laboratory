# ADR-0015: evidence-bound dataflow dashboards instead of reading highlights

The owner rejected animations that merely highlight text cards. Show the technology mechanism, movement of input/results, and an honest comparison with baseline. Use one restrained visual system: dark navy, fine grid, white typography, cyan data, magenta feedback, amber unknowns. Diagrams may differ in topology while sharing the same layout rules and source treatment.

Compile a bounded dataflow-v1 story from the saved report and public presentation fields, or validate an optional motion graph in the same existing research response. Node and edge identities, lanes, roles and evidence references are data, never executable commands. Unsupported or malformed optional graphs fall back locally and never trigger a provider retry. Generic recognized mechanisms are selected from described concepts, without product-name routing. Preserve raw legacy extraction and specialized replay behavior where no supported story is available.

The dashboard includes baseline status (reported, conceptual, or unknown), source notes and scope. A conceptual human-review/CI pipeline or fixed-harness path is labelled as an explanatory reference, not an author's controlled experiment. Unknown DeepInfer baseline remains unavailable instead of fabricating a competitor or result. Traffic is symbolic and normalized; its density or motion speed never encodes an unmeasured performance gain. Author percentages keep their definition and conditions. Benchmark hardware is not presented as a deployment minimum. Public Code Review comments are not automatic merge authority; Harness weights remain fixed; detailed inference routing is explicitly schematic.

Animate packets physically along directed edges, with branches, merges or feedback where the saved account supports them. Keep text, conditions and sources stable and readable at native 1080 px. Provide a static SVG/PNG dashboard and H.264 MP4, including inline playback in the result UI. Reject oversized layouts rather than silently crop conditions or shrink them. New presentation metadata participates in the existing frozen publication signature; owner review remains required before enqueueing a changed package.

Do not alter the six saved reports, post text, usage, approvals, research journals or published files/receipts. Keep the five-weekday Moscow schedule unchanged. Evaluate the three existing examples without new research or channel publication. Verify factual graph constraints, reference validation, real movement/geometry, native MP4 decode and fidelity, readable frames, old behavior, UI playback, and preservation of production records.
