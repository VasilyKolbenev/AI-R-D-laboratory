# 0017. Два компактных оформления по содержанию

Статус: принято, 2026-10-21.

Владелец одобрил компактный дашборд и предоставил презентацию как референс
второго оформления. Её десять слайдов просмотрены как изображения. Выделены
чёрный фон, рукописная типографика, цветные свободные контуры и стрелки.
Факты, инструкции, изображения и чужая атрибуция из слайдов не переносятся.

`visual_skin` выбирается детерминированно после построения `motion_story`:
подтверждённое числовое сравнение или inference → dashboard;
feedback/process/review без сравнения → blackboard. Без подходящего графа
сохраняется dashboard. Нет ротации по случайному числу, названиям продуктов,
дню недели или дополнительного модельного вызова.

Оба оформления используют один механизм, компактный текст, оговорки,
источники и движение пакетов. Доска убирает фоновую сетку, применяет чёрный
фон, Segoe Print из установленной Windows и цветные контуры операций.
Контуры слегка неровные, фиксированы между кадрами, их конечные точки
сохранены. Шрифт измеряется при переносе строк; контейнеры растут по тексту,
без уменьшения кегля и потери подписей. Числовые значения не превращаются
в декоративные длины или неподтверждённые показатели. Новая тема работает
через локальные параметры, без изменения глобальной палитры.

Полное описание стиля входит в существующую подпись публикационного пакета.
PNG/MP4 сохраняются в неизменяемом пакете при предпросмотре. Ранее
опубликованные пакеты сохраняют исходные байты и квитанции; новый апрув
требуется при изменении ожидающего пакета. В очередь ничего не добавляется
автоматически. Расписание не меняется.

Проверка: выбор по содержанию, сохранность фактов/поста, переносы и отсутствие
мутации, независимость параллельных рендеров, движение и нативный экспорт.
Существующие PNG dashboard сравниваются побайтно, оба оформления проверяются
на сохранённых отчётах. Предпросмотр нового оформления отправляется только
в личный чат владельца, без нового исследования и публикации в канал.
