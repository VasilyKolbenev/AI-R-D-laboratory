# Корпус Drift Inspector: первый этап

Это импорт уже опубликованных результатов авторов, а не новое извлечение
утверждений лабораторией. Анализ не запускает LLM, embeddings, кластеризацию,
исследование или публикацию в Telegram. Интерфейс: `/workbench/#corpus`.

## Данные и происхождение

Источник: [Hamyrappy/emnlp-2020-2025-atomic-claims](https://huggingface.co/datasets/Hamyrappy/emnlp-2020-2025-atomic-claims).
Ревизия: `134d196f7c45ef0f3aebcef9f0a06ca98ae95e31`.
Четыре Parquet-файла закреплены по размеру и SHA-256 в инструменте загрузки.
Лицензия набора: CC BY 4.0. Авторы: Vsevolod Karimov, Stepan Ostarkov,
Anastasia Poroshina, Anatoly Frolov, Alexander Panchenko; исходные аннотации —
ACL Anthology. Ссылки на конкретные работы сохраняются.

[Статья и методика](https://aclanthology.org/2026.emnlp-demos.13/).

| Уровень | Размер |
| --- | ---: |
| Полный каталог EMNLP main, 2020–2025 | 6 517 статей |
| Импортированные утверждения | 18 293 из 4 937 статей |
| Каноническая сбалансированная выборка | 4 488 статей, 748 в каждом году |
| Назначения тем в этой выборке | 16 576 утверждений |
| Темы | 80 и отдельная группа шума `-1` |
| Шум внутри выборки | 5 980 утверждений |
| Утверждения вне канонической выборки | 1 717 |

Статья без импортированных утверждений имеет неизвестное покрытие извлечения,
а не «нулевой научный вклад». Отсутствие назначения темы означает нахождение
вне сбалансированной выборки. Шум `-1` находится внутри неё; 656 статей с одними
шумовыми утверждениями также включены в знаменатели.

## Воспроизведение

Числитель: уникальные статьи года хотя бы с одним утверждением выбранной темы.
Знаменатель: все статьи того же года в фиксированной аналитической выборке.
Несколько утверждений одной статьи считаются один раз для данной темы.
Темы могут пересекаться, поэтому сумма долей не обязана составлять 100%.

Пересчитываются все 81 × 6 = 486 значений, включая шум. Опубликованные доли
округлены до четырёх знаков; допуск — 0.00005001 процентного пункта.
Дополнительно проверяются авторские количества статей и утверждений по каждой
теме, уникальность ID, связи и соответствие годов. Несовпадение блокирует импорт;
старый активный снимок остаётся доступен.

Проверочные примеры из этого снимка: Syntactic Parsing — 38 → 1 статья из 748;
Math & Logic Reasoning — 7 → 57. Эти числа описывают корпус авторов, а не результаты
прикладного эксперимента лаборатории.

## Подготовить и импортировать

Остановите приложение перед ручным импортом. Для разового чтения Parquet нужен
изолированный конвертер; рабочему приложению DuckDB/PyArrow не требуются.
Пример PowerShell из корня проекта с установленным 64-битным Python:

```powershell
python -m venv .corpus-converter
.\.corpus-converter\Scripts\python.exe -m pip install duckdb==2.0.0
.\.corpus-converter\Scripts\python.exe -I -S tools/fetch_drift_corpus.py --converter-dir .corpus-converter/Lib/site-packages --output .lab-data/corpus-source/bundle --upstream-dir .lab-data/corpus-source/upstream
.\.venv\Scripts\python.exe -m laboratory.corpus_import --bundle .lab-data/corpus-source/bundle --data-dir .lab-data
```

Инструмент сам не устанавливает пакеты. Скачивание только с закреплённых HTTPS
адресов; кеш проверяется и повторно не скачивается. Для повторной подготовки
можно добавить `--offline`. Исходные Parquet около 8 МБ, нормализованные JSONL.gz
около 4.5 МБ. Загрузка моделей не производится. Для окружения конвертера требуется
дополнительное место на диске; его держат отдельно от рабочего runtime.

Готовый bundle можно перенести на другой компьютер и выполнить только последний
шаг без конвертера и интернета. Повторный импорт тех же входов не создаёт дубликат
снимка. Основная база исследований, настройки и очередь не изменяются.

## Интерфейс и API

- `GET /api/corpus` — каталог, покрытие, происхождение, проверка совпадения и темы.
- `GET /api/corpus/topics/54?year=2020` — статьи числителя и размер знаменателя.
- `GET /api/corpus/topics/54?year=2020&cohort=denominator&offset=0&limit=20`
  — точные статьи знаменателя с пагинацией.
- `GET /api/corpus/papers/2020.emnlp-main.1` — исходная аннотация, метаданные,
  утверждения и их принадлежность темам.

Чтение не создаёт запусков, апрувов, модельных расходов или сообщений.
Даты показываются с точностью исходных данных: известен год, день не придумывается.
Утверждения остаются на английском; автоматического платного перевода нет.

## Границы доказательств и резервирование

Авторские утверждения переформулированы моделью. Дословные supporting quotes/span
в наборе отсутствуют; UI показывает это явно и раскрывает исходную аннотацию.
Совпадение агрегатов не подтверждает истинность каждого утверждения, качество
экстрактора на других корпусах, причинность или эффективность технологии.
Карта эмбеддингов, новые кластеры, собственное извлечение и анализ новых материалов
к этому этапу не относятся.

Файлы `.lab-data/corpora/` — неизменяемый отдельный SQLite, манифест и точные
JSONL.gz входы. Полные эксплуатационные копии включают и проверяют этот каталог;
проверочное восстановление читает корпус без запуска сервера/бота. Обычный JSON
экспорт основной истории корпус не включает: сохраните полную локальную копию
либо повторите импорт того же bundle.

## Следующие возможности — предложения

1. **Разница снимков:** новые статьи и причины изменения каждой точки тренда.
   Ближайший приоритет: делает накопление корпуса полезным без новых оценок модели.
2. **Линза покрытия:** где не хватает аннотаций/извлечений. Пропуски не называть
   научными пробелами без дополнительной проверки.
3. **Когорты:** сравнение авторов, конференций и периодов с видимыми знаменателями.
4. **Долг доказательств:** связи популярных утверждений с независимыми проверками;
   отсутствие найденной проверки не считать опровержением.
5. **Маршрут исследования:** вопрос → аналоги → несовпадающие условия → самый
   дешёвый следующий тест с отдельным планом и апрувом.

Это направления дальнейшего развития, не работающие функции этого этапа.
