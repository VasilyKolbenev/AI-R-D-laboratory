# Первый запуск · v0.20.0-alpha.1

Поддерживаемый путь альфы: Windows x64, CPython 3.11–3.13, один владелец.
Для PNG/MP4 установщик добавляет Pillow 12.3.0 и imageio-ffmpeg 0.6.0
в отдельное окружение. GPU и локальные модели не нужны.

## Установка

1. Установите x64 Python с [python.org](https://www.python.org/downloads/windows/).
   Для обычного запуска Setup установите Python Launcher (`py`).
2. Скачайте архив приложения из [Releases](https://github.com/VasilyKolbenev/AI-R-D-laboratory/releases).
   Сверьте SHA-256 с контрольными суммами релиза:
   `Get-FileHash .\имя-архива.zip -Algorithm SHA256`.
3. Полностью распакуйте в короткий доступный путь, например `C:\AI-Lab`.
   Не запускайте файлы внутри ZIP или из `Program Files`.
4. Запустите `Setup-Laboratory.cmd`. Для явного Python:
   `Setup-Laboratory.cmd --python "C:\Path\To\python.exe"`.
5. После успешной установки откройте `Open-Laboratory.cmd`, затем
   [http://127.0.0.1:8795](http://127.0.0.1:8795).

Setup использует интернет для PyPI и создаёт `.venv` и `.lab-tools/media`.
Он не запускает исполнителей и не включает автозапуск.
Остановка: `Stop-Laboratory.cmd`. Для второй копии передайте `--port 8796`
при открытии и тот же порт при остановке. Не останавливайте чужой процесс.

## Сначала — без модели

1. Во «Входящих» добавьте короткий публичный текст или URL.
2. В «Задачах» задайте прикладной вопрос, текущий подход (baseline), ожидаемую
   пользу и метрику. Можно начать без задачи, но сравнение будет менее конкретным.
3. В настройках заполните интересы и предпочтения; добавьте поправку,
   например «не смешивать разные наборы данных в графике».
4. Подготовьте план. Найдите материал, задачу, память, уроки,
   исполнителя, число проходов, время и суточный лимит.
5. Закройте план, **не подтверждая запуск**. Подготовка плана и сохранение
   материала не обращаются к модели.

В `/concepts/` находятся синтетические визуальные прототипы, отдельные от
реальных исследований и вашей базы. Новая база не содержит чужих отчётов.

## Исполнитель и режим

Установите официальный нативный CLI и войдите в свой аккаунт по документации:
[Codex](https://learn.chatgpt.com/docs/cli),
[Claude Code](https://code.claude.com/docs/en/quickstart).
Приложение обнаруживает исполняемый файл; это ещё не подтверждает,
что ваш аккаунт разрешает нужную модель, веб-поиск или выбранный режим.

На Windows нужен нативный `.exe`, доступный в PATH или поддерживаемой папке
официального приложения. Batch-обёртки `.cmd` не исполняются адаптером.
В ходе подготовки релиза проверены справка и обнаружение
`codex-cli 0.164.0-alpha.11.1`; Claude CLI в этой среде не был установлен.
Проверки адаптеров используют фикстуры; новый облачный прогон для выпуска
не выполнялся. При несовместимой версии сохраните ошибку из журнала, не
запускайте повтор до проверки плана и возможного расхода.

В новой базе: один проход, 180 секунд, 3 вызова CLI за 24 часа; веб-поиск
и расширенная работа с первоисточниками выключены. В настройках или форме
плана **явно выберите три прохода с критиком и нужные параметры источников**
до его подготовки. Три прохода резервируют три слота: при квоте 3 это одно
полное исследование за 24 часа. Квота сама не повышается.

Свои подписку и лимиты предоставляет пользователь. Ограничение по времени
не гарантирует расход токенов. Перед апрувом проверьте точный контекст:
выбранные материалы будут переданы внешнему исполнителю.
Приватные данные используйте только при наличии нужных прав.

## Личный Telegram-бот

1. В [@BotFather](https://t.me/BotFather) создайте отдельного бота: `/newbot`.
2. В «Настройках → Материалы из Telegram» введите токен.
3. Откройте бота и отправьте команду привязки, показанную локальным интерфейсом.
4. Перешлите текст с первичной ссылкой. Проверьте подготовленный план,
   память и бюджет; подтвердите только если готовы к расходу.
5. Получите результат в Telegram; полный отчёт и журнал — в базе знаний.

Токен и код привязки не публикуйте в Issues или скриншотах.
Используется polling: входящий сетевой порт не нужен. Не запускайте второй
приёмник того же бота. Бот с существующим webhook отклоняется; лаборатория
не удаляет чужой webhook.

Фото, аудио и произвольные вложения не гарантируют доступный текст.
Передавайте текст или расшифровку и проверяйте план до запуска. Старую историю
можно импортировать JSON-экспортом из Telegram Desktop во «Входящие».

## Посты и канал

Канал не нужен для исследований. Для публикации подключите свой канал,
добавьте бота администратором с правом публикации и задайте дни и время.
Свежая установка не включает канал или расписание автора.

Просмотрите текст, PNG и MP4. «В очередь» отдельно одобряет этот пакет и
показывает слот; повтор не создаёт второй пакет. Пустой слот пропускается,
новое исследование не инициируется. Компьютер должен работать, не спать
и иметь сеть. При неизвестном исходе отправки сначала проверьте канал:
автоматического повтора неопределённой публикации нет.

## CPU-проверка поиска

Необязательный отдельный сценарий. Скачайте BEIR/SciFact:
`.venv\Scripts\python.exe tools\fetch_scifact.py`.
Загрузка сохраняет данные и ещё не запускает оценку.

В `/workbench/` → «Эксперименты» подготовьте и отдельно подтвердите план.
Один CPU-прогон сравнивает TF-IDF и BM25; моделей и API нет.
[Условия](research/lexical-pilot.md). Результат автора в чистую базу не переносится.

## Обновление и восстановление

Сделайте полную копию в настройках, затем остановите приложение.
Распакуйте новую версию в отдельную папку, выполните Setup и следуйте
инструкции конкретного релиза. Автоматической миграции между папками нет.
Не копируйте `.venv`: окружение привязано к пути.

Полный backup восстанавливайте в новую пустую папку данных по
[инструкции](operations.md). DPAPI требует того же Windows-профиля.
После восстановления публикация заблокирована до проверки состояния канала.

JSON-экспорт знаний не заменяет полный backup: в нём нет подключения бота,
публикационных медиа и очереди. Для защиты от поломки диска храните отдельную
копию на выбранном вами носителе.

## Если не запускается

| Симптом | Что проверить |
| --- | --- |
| Python не найден | Установлен ли x64 CPython 3.11–3.13; передайте `--python` |
| Setup не скачивает зависимости | Доступ к PyPI и сертификаты; не отключайте TLS |
| Порт занят | Эта копия уже открыта или нужен отдельный порт |
| Не обнаружен исполнитель | Установлен ли нативный CLI; поддерживается ли версия и вход |
| Нет MP4 | Завершился ли Setup; SVG/GIF могут остаться доступны |
| Telegram не принимает | Привязка владельца, один приёмник, ПК и сеть |
| `outcome_unknown` | Возможен расход; изучите журнал до нового апрува |

Для [ошибки](../CONTRIBUTING.md) нужны версия, Windows/Python, шаги и
обезличенный текст. Не прикладывайте рабочую базу и токены.
