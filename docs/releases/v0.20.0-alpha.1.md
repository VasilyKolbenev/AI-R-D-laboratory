# VV Frontier · v0.20.0-alpha.1

Local Windows x64 alpha: material → approved plan and selected memory →
research → report and visuals → knowledge base. Publishing a Telegram package
requires a separate owner approval.

## Install

1. Install x64 CPython 3.11–3.13.
2. Download the application ZIP attached to this release; verify SHA-256 against
   the attached checksums and extract to a short path such as `C:\AI-Lab`.
3. Run `Setup-Laboratory.cmd`, then `Open-Laboratory.cmd`.
4. Open `http://127.0.0.1:8795`; stop with `Stop-Laboratory.cmd`.

Setup downloads pinned Pillow, pypdf and imageio-ffmpeg from PyPI into a local environment.
It does not start research or connect a bot. A native Codex or Claude CLI with your
own login is optional until you approve a study. Subscriptions and models are
not bundled. [Русская инструкция](https://github.com/VasilyKolbenev/AI-R-D-laboratory/blob/v0.20.0-alpha.1/docs/getting-started.md) · [Pilot](https://github.com/VasilyKolbenev/AI-R-D-laboratory/blob/v0.20.0-alpha.1/docs/pilot.md).

## Included

- Telegram text/URL intake and JSON import; exact plan approval.
- Personal memory and lessons with evidence/scope; applied baseline and metrics.
- One pass or opt-in researcher → critic → editor, usage journals and checkpoints.
- Reports, comparable-number charts, PNG/SVG and MP4 explanations.
- Owner-approved Telegram queue with your configured schedule.
- Fixed CPU-only TF-IDF/BM25 evaluation on separately downloaded SciFact data.
- Local backup, restore checks, exports and crash supervision.

New installations default to one pass, 180 seconds, three CLI calls per 24 hours
and web search off. Enable reviewed three-pass mode explicitly before preparing
a plan; it reserves three calls without silently increasing the quota.

## Limits

Single-owner localhost application for a small Windows pilot, not a shared hosted
service. The computer must be on and online for Telegram/publication. Same-disk
backups do not protect against disk failure; DPAPI secrets depend on the profile.

Source analysis is not an executed technology benchmark; schematic motion is not
measured speed. A model timeout can leave an unknown paid outcome and does not
trigger automatic retry. The archive contains no author's database, research
results, tokens or queue.

Linux/macOS, multi-user isolation, automatic updates and arbitrary benchmarks are
outside the supported scope. Setup checks do not establish long-term uptime,
every provider CLI/account combination or scientific correctness.

## Safe first try

Add a public text, prepare a plan, inspect memory/budget and close without approval:
zero model calls. Use [the pilot card](https://github.com/VasilyKolbenev/AI-R-D-laboratory/blob/v0.20.0-alpha.1/docs/pilot.md#карточка-обратной-связи) for
sanitized feedback. Each real study and publication is a separate decision.

Before upgrading, make a full backup, stop the old version and use a separate
folder; see [update/restore](https://github.com/VasilyKolbenev/AI-R-D-laboratory/blob/v0.20.0-alpha.1/docs/getting-started.md#обновление-и-восстановление).
