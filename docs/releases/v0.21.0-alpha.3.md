# VV Frontier · v0.21.0-alpha.3

VisualSpec v1 adds a deterministic, read-only visual plan to existing saved-data
APIs: `/api/runs/{id}/research.visual_spec` and `/api/corpus.visual_spec`.
The plan records input bindings, primary figure, ordered blocks, sources,
provenance, assumptions and reasons for selected or deferred visualizations.

The brief prioritizes eligible numerical comparisons, otherwise a bounded saved
mechanism, otherwise a concise contextual summary. Corpus trends remain prevalence
within their exact frozen sample, not technology effectiveness. Ineligible views
are omitted or disclosed with their missing inputs. The UI explains its choice.

Preferred engines (Infographic/G2/G6, custom interactive explainers, Manim) are
recorded separately from the installed native DOM/SVG adapters. This increment
does not install those packages or run arbitrary generated render code. Simulators
and video require an additional concrete model/rendering recipe.

Plans, approvals, reports, knowledge records, publication packages, corpus bytes
and budgets are preserved. Opening or selecting a view does not start research,
fetch scientific sources, translate, benchmark or send Telegram messages.

See [VisualSpec contract and routing](../research/visual-spec.md).
