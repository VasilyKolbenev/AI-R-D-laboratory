# VV Frontier · v0.21.0-alpha.2

The default research view is now a concise visual brief at `/?run=<id>`. It reads
the saved report, readiness projection and versioned memory references. The first
screen prioritizes the working task, mechanism, comparison, applicability and
limits; supporting text is disclosed on demand.

Numeric plots use only source-bound, comparable measurements marked
`chart_eligible` by the existing readiness projection. Author-reported numbers
remain labelled as reports, not local experiments. Unknown values are never zero.
Context-only memory records are not presented as competing technologies, and
formal report checks are not a score of scientific validity.

The original Reactor is under Tools (`?mode=reactor`); Observatory remains available
through Tools and `?mode=evidence`. Detailed history, corpus, task configuration,
research approvals and the Telegram publication gate retain their existing paths.
Opening the brief does not run a model, benchmark, translation or publication.

For legacy reports without measurements, the visual brief shows saved qualitative
mechanism and explicit gaps. It cannot create absent evidence or establish a
technology's effectiveness by changing the presentation.
