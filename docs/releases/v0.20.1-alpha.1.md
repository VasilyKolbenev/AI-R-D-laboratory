# VV Frontier · v0.20.1-alpha.1

Patch for two defects found during the first maintainer Telegram pilot.

- GitHub captures select the README before applying text/segment limits. Preparing
  a new plan can append a corrected projection of cached original bytes, keeping
  their retrieval timestamp, raw SHA-256 and lineage. No HTTP is needed for this
  operation; old plans and evidence are never rewritten.
- Long drafts try shorter static headings and notices before failing the length
  check. All mandatory narrative paragraphs, numeric conditions and sources stay
  whole. The 3500 UTF-16 limit remains; genuinely oversized drafts remain blocked.

The saved pilot report stays a qualitative source review. Parser repair does not
add numbers to an already completed model answer or authorize another study.

Windows x64 / CPython 3.11–3.13: extract the attached ZIP into a new short path,
run `Setup-Laboratory.cmd`, then `Open-Laboratory.cmd`. Dependencies and setup are
unchanged from v0.20.0-alpha.1. Back up and stop an existing installation before
upgrading; preserve your data and use the documented restore procedure.

No automatic model retry, quota change or Telegram channel publication is introduced.
Independent-user installation remains a pending pilot, not a completed claim.
