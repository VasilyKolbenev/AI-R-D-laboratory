# VV Frontier · v0.21.0-alpha.4

Actual local AntV renderers now consume VisualSpec's accepted data. Saved SLEEP
uses a responsive Infographic sequence with evidence selection on its exact nodes.
Drift Inspector uses G2 corpus trend plots with the same numerical shares,
denominators, year selection and source-article drilldown as the previous view.

The browser bundles are AntV Infographic 0.2.20 and G2 5.4.8, copied byte-for-byte
from SHA-512-verified npm distributions. Source licenses and file hashes are
retained. Local script routes have SHA-384 integrity attributes; the application
does not add external CDN, font/icon services or CSP exceptions. The app's Python
runtime does not gain npm, renderer build tools or a model dependency.

The Infographic adapter only maps a supported linear process; branching,
feedback and semantic edge labels stay in the native graph. Load/render errors
fall back with an explicit reason, never fabricated values or topology.
The current renderer is reported in the UI rather than inferred from preference.

No reports, approvals, memory records, research budgets, corpus inputs or frozen
Telegram packages are regenerated. Opening the views does not run research,
benchmark a technology or publish a post. The change is visual presentation only.
