VV Frontier — исследовательский стол / предпросмотр

Запуск: python preview_server.py
Адрес: http://127.0.0.1:8797/
Для данных должна работать основная локальная лаборатория на порту 8795.

Это отдельный вариант интерфейса. Он читает существующие исследования,
представления, аудит, прикладные записи и очередь через явный список GET API.
Сервер привязан только к 127.0.0.1. Внешние адреса, перенаправления,
произвольные пути и запросы с параметрами запрещены. Шрифты и интерфейс локальные.

Предпросмотр не запускает исследования и не вызывает модели, не создаёт план,
не сохраняет апрув, не меняет память и не отправляет ничего в Telegram.
Все изменяющие HTTP методы отклоняются. Рабочий «Реактор» на порту 8795
не заменяется и не перезапускается. Его обычное расписание остаётся действующим.

Чтобы закончить работу предпросмотра при обычном запуске, нажмите Ctrl+C
в его терминале. Новых задач автозапуска он не создаёт.
