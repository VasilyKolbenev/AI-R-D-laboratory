3 ПРИМЕРА
M-042Обновление предпочтенияПРОЙДЕНО / EVENT

Вход: сначала пользователь просит отвечать на английском, затем меняет предпочтение на русский. Позже спрашивает о результатах исследования.

Ожидаемое поведение: ответить по-русски, используя последнее действующее предпочтение.

Проверка: язык ответа + ссылка памяти на актуальное событие. В примере Event memory проходит проверку, Vector memory извлекает устаревшую запись.

fixture: memory-demo-v1 / scenario: M-042

M-087Цитата принята за новое событиеОШИБКА / EVENT

Вход: встреча перенесена с 10 на 12 октября. Позднее сообщение цитирует первоначальную дату и задаёт вопрос об изменении.

Ожидается: 12 октября. Демонстрационный ответ: 10 октября.

Причина ошибки: порядок записей ошибочно заменяет анализ смысла обновления. Повторный запуск должен отдельно проверять цитаты, отмены и исправления.

fixture: memory-demo-v1 / scenario: M-087
