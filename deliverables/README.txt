R&D Laboratory — проектный пакет / 07.10.2026

Распакуйте весь архив и откройте index.html в современном браузере.
HTML, SVG и графики работают без сервера и сетевого соединения.
Для совместной работы со ссылками храните структуру папок.

docs/architecture.html — архитектура C4, интеграции и контракты.
docs/implementation-plan.html — целевой план альфы за 4–5 недель и приёмка.
docs/claude-task-001.html — первое задание Claude Code для ручной передачи.
architecture/alpha-acceptance.json — требования альфы, проверки и статусы.
docs/research-catalog.html — объекты исследования, задачи, метрики.
ui/01-observatory.html — тёмный рабочий dashboard.
ui/02-atelier.html — светлая аналитика и отчёты.
ui/03-constellation.html — выбранный Constellation v2, полный локальный UI-сценарий.
ui/03-constellation-v1.html — сохранённая первая концепция.
docs/constellation-ux-review.html — сверка функций и изменений v2.
architecture/ — исходные DOT, векторные SVG, JSON Schema и примеры.
qa/verification.html — выполненные проверки и границы их охвата.

Показатели в UI синтетические. Запуск — локальная демонстрация.
API моделей не подключены. Реальных исследований и расходов нет.
Источники, планы и настройки Constellation v2 сохраняются только в браузере.
Это не облачное или защищённое хранилище; не вводите реальные API-ключи.
Реальный Telegram, модели, извлечение PDF и исполнители здесь не подключены.

Архитектура и план описывают предлагаемую будущую реализацию.
Пример плана содержит явно обозначенные фиктивные хеши и artifact URI.
Он проверяет форму контракта и не предназначен для реального запуска.

Опциональный просмотр через localhost:
  python -m http.server 8794 --bind 127.0.0.1
Откройте http://127.0.0.1:8794/ в браузере. Команду запускайте
из папки, где находится index.html. Остановка сервера: Ctrl+C.

Разработка артефактов:
  Python 3: build_diagrams.py создаёт DOT (только стандартная библиотека).
  Node.js + @viz-js/viz: render_diagrams.cjs создаёт SVG.
  Node.js + Playwright + Microsoft Edge: qa/*-check.cjs проверяет UI.
  Python 3 + jsonschema: qa/package-check.py проверяет ссылки и схему.
Зависимости генераторов и проверок: npm ci в этой папке и pip install -r requirements-docs.txt.
Для браузерных проверок установите Chromium: npx playwright install chromium.
PLAYWRIGHT_CHANNEL=msedge позволяет использовать установленный Microsoft Edge.
Для просмотра готовых материалов эти зависимости не нужны.

Проверка второй итерации: qa/constellation-v2-check.cjs --revision-ready.
Проверяется новый HTML в изолированном тестовом окружении без сети.
qa/constellation-v2-results.json содержит SHA-256 проверенной версии.
Исходный interaction-check.cjs относится к первой итерации концепций.

Цель новой реализации: приватная альфа за 4–5 недель от старта.
Claude Code разрабатывает, Codex проводит техническое руководство и приёмку.
Задания и отчёты между ними вручную передаёт пользователь.
Пути в TASK-001 относятся к корню рабочего репозитория AI-R-D-laboratory.
Этот архив содержит проектные материалы, а не полный снимок репозитория.
