Публикация в канал

Только готовые выпуски после вашей кнопки «В очередь»

Настройки публикации ещё не загружены.

Добавьте бота администратором канала с правом публикации. Подключение проверяет права; оно не публикует посты и не включает расписание. При смене канала готовые выпуски нужно одобрить заново.

Дни и время — по Москве. Выберите удобные часы выпуска. Подключение канала не меняет расписание.

Пустая очередь пропускает слот. Новые исследования не запускаются. Для отправки лаборатория должна работать на компьютере.

Исполнитель исследований

Официальный CLI и ваш обычный вход в аккаунт

Каждый вызов CLI использует лимит выбранного аккаунта. Одно исследование с тремя проходами резервирует 3 вызова; при лимите 3 доступно одно такое исследование за 24 часа. Ограничение по времени не гарантирует определённый расход недельного лимита.

Материалы из Telegram

Пересылайте выбранное из «Избранного» своему боту

  1. Создайте бота у @BotFather командой /newbot.
  2. Введите его токен здесь. Он останется в локальной настройке.
  3. Откройте бота и отправьте команду привязки, которая появится ниже.
Отправьте боту

Перешлите материал: бот подготовит план с памятью и уроками. После вашего апрува кнопкой он пришлёт выводы и материалы для поста; полный отчёт сохранится в базе знаний. Лаборатория должна работать на компьютере. Для накопленной истории экспортируйте «Избранное» из Telegram Desktop в формате JSON и импортируйте файл во «Входящих».

Работает и сохраняется

Автозапуск · ежедневные полные копии · проверка восстановления

Проверяем состояние…
Границы автоматизации

Компьютер должен быть включён и иметь интернет. После перезагрузки нужен вход в этот профиль Windows. Копии хранятся локально: защита от потери диска требует отдельного носителя. Зашифрованный токен восстанавливается в том же профиле. Проверка восстановления не запускает бота и ставит восстановленные выпуски на паузу, чтобы не отправить их дважды.

Переносимая копия знаний

Дополнительный экспорт для переноса материалов

JSON содержит материалы, планы и исследования.

Токен Telegram, очередь и медиа в этот экспорт не включаются. Для всей рабочей лаборатории используйте полную копию выше. Восстановление JSON доступно только в пустую базу.

Автоматические проверки оценивают структуру, происхождение данных и обработку замечаний. Они не заменяют независимую проверку важных научных выводов.
